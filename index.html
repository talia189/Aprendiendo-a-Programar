What is Programming and What is it Used For?

Programming is giving precise instructions to a computer through code to perform specific tasks or solve problems automatically.

What is it used for? It allows you to automate repetitive tasks, process massive amounts of data at high speeds, solve complex problems, and build interactive applications.

2

What Can We Program?

Programming encompasses various fields of modern software:

  • Websites and Web Apps: E-commerce platforms, social networks, management systems.
  • Mobile Applications: Tools for iOS and Android.
  • Artificial Intelligence: Algorithms for predictive analysis and machine learning.
  • Embedded Systems & IoT: Smart devices and robotics.
3

How to Start Programming?

To get started, you don't need an advanced math background; instead, follow an organized methodology:

  1. Define a area: Web development is highly recommended due to its fast learning curve.
  2. Set up your environment: Code editor and web browser.
  3. Learn basic logic: Variables, conditionals, and loops.
  4. Build real projects: Apply what you learn by creating small applications.
4

Guide from Scratch: HTML, CSS, and JS

The foundation of web development consists of three primary technologies:

1. HTML (Structure): Layouts the page elements (text, buttons, images).
2. CSS (Styles): Defines visual presentation, colors, and responsive layouts.
3. JavaScript (Logic): Provides dynamic behavior and response to user actions.

5

Ch. 1: Algorithms and Logic

An algorithm is a finite, ordered, and unambiguous sequence of steps designed to solve a specific problem.

Key Concepts:

  • Variables: Memory spaces used to store changing data.
  • Constants: Fixed values that remain constant during execution.
  • Conditionals (if/else): Make decisions depending on whether a condition is met.
6

1.2 Loop Structures

Loops or iterations allow executing a block of code multiple times while a specified condition holds true.

  • For Loop: Used when the exact number of iterations is known beforehand.
  • While Loop: Executes code as long as the condition remains true.
  • Do-While Loop: Guarantees at least one execution before evaluating the condition.
7

Ch. 2: Development Environments

2.1 Visual Studio & VS Code: To write code efficiently, an editor is required. VS Code is a lightweight, fast, and highly expandable editor via plugins, perfect for web. Visual Studio is a full IDE geared towards complex desktop or enterprise apps.

8

2.2 Local Servers: Laragon

Laragon is a development environment for Windows that simulates a real web server on your machine. It integrates key tools such as:

  • Apache / Nginx: Servers handling HTTP requests.
  • PHP: Server-side processing language.
  • MySQL: Relational database management system.
9

Ch. 3: Programming Paradigms

3.1 Sequential Programming: The most direct approach. Instructions execute strictly linear, one after another, from top to bottom of the file.

10

3.2 Event-Driven Programming

In this paradigm, program execution is determined by external events such as user clicks, key presses, or network responses. Widely used in graphical interfaces and modern web applications.

11

3.3 Object-Oriented Programming (OOP)

Organizes code around Classes (blueprints) and Objects (instances). Built upon four main pillars: Encapsulation, Inheritance, Abstraction, and Polymorphism.

12

Ch. 4: Development Methodologies

4.1 The Spiral Model: Software development methodology focused on risk management. Combines iterative nature with systematic aspects of the waterfall model.

Main phases: Planning, Risk Analysis, Engineering, and Customer Evaluation.

13

4.2 Agile Methodologies: Scrum

Scrum divides work into short iterations known as Sprints (1 to 4 weeks long). Encourages fast value delivery, continuous collaboration, and adaptability to change.

14

Ch. 5: Version Control with Git

Git is a distributed version control system that tracks code changes. Allows rolling back to previous versions and working collaboratively using branches.

GitHub: Cloud platform for hosting Git repositories.

15

Ch. 6: Front-End Development

Includes the user interface visible in the web browser.

HTML: Semantic structure using tags (<header>, <main>, <footer>).
CSS: Styling, Flexbox, and Grid for flexible layouts (Responsive Design).

16

6.2 JavaScript and the DOM

The Document Object Model (DOM) is the tree-like representation the browser makes of HTML. JavaScript manipulates the DOM to change content, styles, and handle user events in real time.

17

Ch. 7: Back-End Development with PHP

PHP processes requests on the server before sending results back to the browser. It manages authentication, form data validation, and transaction handling.

18

7.2 Full-Stack Integration

Combining the client side (HTML/CSS/JS) with server logic (PHP) creates complete and interactive applications known as Full-Stack developments.

19

Ch. 8: Databases and SQL

Relational databases organize information into structured tables with rows and columns using SQL language.

Main statements: SELECT, INSERT, UPDATE, DELETE.

20

8.2 Table Relationships

Through Primary Keys and Foreign Keys, tables can be linked together to maintain data integrity without unnecessary redundancy.

21

Ch. 9: Web Security

Security must be considered from the start of development. Common vulnerabilities:

  • SQL Injection: Prevented by using prepared statements.
  • XSS (Cross-Site Scripting): Prevented by sanitizing user input.
22

9.2 Code Best Practices

Writing Clean Code enhances system maintainability and scalability:

  • Use descriptive names for variables and functions.
  • Keep functions short with a single responsibility.
  • Comment code only when strictly necessary.
23

Ch. 10: Deployment and Maintenance

Once developed and tested in the local environment (Laragon), the application is deployed to a production server (Hosting / VPS) with a domain name and SSL certificate (HTTPS).

24

Software Lifecycle

Development doesn't end with deployment. It includes error monitoring, security updates, performance optimization, and ongoing user support.

25

Final Summary

With knowledge of logic, code editors, version control, paradigms, front-end, back-end, and databases, you have a solid foundation to build full-stack tech solutions.
